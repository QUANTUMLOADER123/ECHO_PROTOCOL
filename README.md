# 📡 ECHO PROTOCOL: NEON SWARM

**Залипательный неоновый roguelite-шутер на телефон в одно касание.**
Ты — последний сигнал в цифровом аду. Игра стреляет сама — ты уворачиваешься, собираешь опыт и создаёшь армию **ЭХО-клонов**, которые повторяют твой путь и стреляют вместе с тобой.

## 🎮 Как играть
- 👆 **Веди палец** по экрану — сигнал летит за ним (на ПК: мышь / WASD / стрелки)
- 💠 Собирай осколки опыта с уничтоженных врагов
- 🃏 Каждый уровень — выбор **1 из 3 усилений**: собери сломанное комбо
- 👻 Качай **ЭХО** — до 5 призраков повторяют твою траекторию
- ⚡ **РЫВОК** — кнопка / двойное касание кнопки / `Space`: неуязвимость + скорость
- 👹 Босс каждую минуту. Комбо-множитель очков за серии убийств

**Враги:** преследователи, ткачи (синусоида), рывковые (телеграф → рывок), сплиттеры (делятся на 3), босс-октагон с кольцевыми залпами.

## 📱 Скачать APK
Готовый `ECHO_PROTOCOL.apk` — в [Releases](https://github.com/QUANTUMLOADER123/ECHO_PROTOCOL/releases) репозитория и в артефактах GitHub Actions (workflow **Build APK**). Установка: открыть файл на телефоне → разрешить установку из этого источника. Android 7.0+ (API 24+), размер ~100 КБ, интернет не нужен, рекламы нет.

## 🛠 Структура
```
game/index.html          — вся игра одним файлом (Canvas + WebAudio, без ассетов)
index.html               — копия для веб-превью / GitHub Pages
android/                 — нативная WebView-обёртка (Java, без зависимостей)
.github/workflows/       — GitHub Actions: сборка APK при каждом пуше
```

## 🔨 Собрать самому
```bash
# нужен JDK 17 + Android SDK + Gradle 8.7+
cd android && gradle assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```
Либо просто запушь в `main`/рабочую ветку — GitHub Actions соберёт APK сам.
