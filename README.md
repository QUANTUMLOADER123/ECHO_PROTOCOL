## Как открыть и собрать (на твоём ПК)

1. Установи **Unreal Engine 5** (5.3+) через Epic Games Launcher.
2. Установи **Visual Studio 2022** с нагрузкой «Разработка игр на C++».
3. Скалонируй репозиторий:
   ```bash
   git clone https://github.com/QUANTUMLOADER123/ECHO_PROTOCOL.git
   cd ECHO_PROTOCOL
   git checkout arena/559294b5-echo-protocol
   ```
4. Запусти UE Editor → выбери `ECHO_PROTOCOL.uproject`.
5. Редактор предложит сгенерировать файлы Visual Studio — согласись.
6. Открой `ECHO_PROTOCOL.sln` в Visual Studio 2022.
7. Выбери конфигурацию **Development Editor** или **Shipping**, платформа **x64**.
8. **Build → Build Solution**.
9. В редакторе создай Blueprints по `Docs/BLUEPRINTS_GUIDE.md`.
10. Собери карты по `Docs/Level_Design_*.md`.
11. **File → Package Project → Windows** → получишь папку с `.exe`.
12. Архивируй в `.zip`, положи в `Builds/` и запушь на GitHub.

## Что я сделал (весь код текстом)

Все системы написаны на C++ и готовы к компиляции:
- **Оружие**: 6 типов, модульность (4 слота модов), патроны, перезарядка
- **Гаджеты**: 8 типов (сканер Эхо, глушилка, дрон, якорь реальности, ложный сигнал, взломщик, аптечка)
- **Инвентарь**: карман vs контейнер, закреплённое оружие, патроны
- **Лут**: флешки, терминалы, тела, ключ-карты, документы
- **Контракты**: разведка / диверсия / спасение, прогресс, награды
- **База-хаб**: верстак, медотсек, архив, оружейная, уровни объектов
- **Перки**: дерево «Протоколов» (6 перков с предварительными условиями)
- **Сохранения**: JSON-профиль, кредиты, репутация, закреплённый лут
- **Сеть**: кооператив до 4 игроков, репликация здоровья, тревоги, эвакуации
- **UI**: HUD, Эхо-слой HUD, брифинг, меню базы, дерево перков
- **ИИ**: 7 типов врагов (патруль, дрон, фантом, турель, снайпер, стая, Титан)
- **Процгенерация**: граф комнат + ручные якоря, валидация проходимости
- **Стелс**: присед, лежание, скольжение, маскировка, шум, обнаружение
- **Эхо-слой**: заряд + кулдаун, ослабление оружия, визуальные искажения
- **Тревога**: шкала 0-100, блокировка локации на 100, естественное затишье
