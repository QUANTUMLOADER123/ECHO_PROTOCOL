# Спецификации Behavior Trees для ИИ

## Патруль (BT_Patrol)
1. **Патрулировать** — движение по точкам маршрута (NavMesh)
2. **Ожидать** — пауза на точке (2-5 сек)
3. **Обнаружение шума** — переход в Investigate если услышал игрока
4. **Расследование** — движение к источнику шума
5. **Поиск** — обход области вокруг последней известной позиции
6. **Возврат** — возврат к патрулю если игрока не нашел
7. **Бой** — атака если игрок в линии зрения
8. **Вызов подкрепления** — если тревога > 50

## Дрон-адаптор (BT_Drone)
1. **Сканирование** — облет области с радиусом 1000
2. **Обнаружение** — запоминание позиции игрока
3. **Изменение маршрута** — адаптация к действиям игрока
4. **Атака** — стрельба если игрок в зоне поражения
5. **Уязвимость к ЭМИ** — выход из строя при попадании ЭМИ-винтовки

## Фантом (BT_Phantom)
1. **Активация в Эхо-слое** — существует только там
2. **Ментальная атака** — искажение HUD игрока,кража заряда Эхо
3. **Ложные метки** — создание фиктивных меток на компасе
4. **Смерть от Якоря реальности** — урон при использовании гаджета игрока

## Турель (BT_Turret)
1. **Стационарное наблюдение** — сканирование сектора
2. **Атака** — стрельба при обнаружении
3. **Взлом** — может быть взломана игроком и перевернута на врагов

## Снайпер (BT_Sniper)
1. **Позиция на высоте** — статическая позиция
2. **Лазерный прицел** — метка на игроке перед выстрелом
3. **Выстрел** — высокий урон, пробитие
4. **Требование обхода** — игрок должен обходить, а не ломать в лоб

## Стая (BT_Swarm)
1. **Массовое движение** — окружают игрока
2. **Реакция на свет/звук** — притягиваются к фонарям и выстрелам
3. **Атака стаей** — Simultaneous ataque из нескольких направлений

## Титан (BT_Titan)
1. **Босс-бой** — несколько фаз
2. **Атаки области** — удары по área
3. **Призыв подкрепления** — спавн дронов и патрулей
4. **Смерть** — отключение турелей, открытие проходов, снижение тревоги

## Дерево перков (Perk Tree)
| Перк | Стоимость | Эффект | Предварительные условия |
|------|-----------|--------|------------------------|
| Тихие шаги | 100 | Шум шагов -50% | — |
| Быстрый взлом | 150 | Взлом на 30% быстрее | Тихие шаги |
| Доп. заряд Эхо | 200 | +1 заряд Эхо-слоя | Быстрый взлом |
| Крепкий контейнер | 250 | Теряется меньше лута при смерти | Доп. заряд Эхо |
| Лучшая маскировка | 300 | Маскировка длится дольше | Крепкий контейнер |
| Более патронов | 350 | +50% резерв патронов | Лучшая маскировка |
