# Дизайн уровня: M_Cobalt — Завод «Кобальт»

## Обзор
Первая локация. Биом: ржавчина, пар, конвейеры, искры. Враги: дроны-адапторы, турели.

## Ручные якоря (Anchor Rooms)
1. **Серверная** — терминал с данными, Goal контракта
2. **Комната охраны** — патрули, камеры
3. **Лифт** — точка перехода между этажами
4. **Оружейная** — лут, патроны

## Процедурная генерация
- Корридоры между якорями (процедурные)
- Залы с конвейерами (процедурные)
- Площадки с турелями (процедурные)

## Враги
- Дроны-адапторы (летают, сканируют)
- Турели (стационарные, взламываются)

## Цели контракта
- Флешка с производственными логами (DataStick)
- Терминал с данными ИИ (Terminal)

## Эвакуация
- Точка эвакуации на крыве или на улице
- Дистанция зависит от тревоги

## Технические требования
- Карта: `M_Cobalt`
- Освещение: industriel, оранжево-красный пар
- Навигация: NavMesh + динамические препятствия (конвейеры)
- Звук: эмбиент завода
