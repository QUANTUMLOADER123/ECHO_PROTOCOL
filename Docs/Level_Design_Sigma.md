# Дизайн уровня: M_Sigma — Лаборатория «Сигма»

## Обзор
Биом: белый кафель, красный аварийный свет, стерильность. Враги: фантомы, камеры.

## Ручные якоря
1. **Серверная с образцами** — Goal контракта
2. **Комната охраны** — патрули в экзоскелетах
3. **Лифт** — переход между секторами
4. **Оружейная** — лут

## Процедурная генерация
- Белые коридоры с кафелем
- Лабораторные залы с столами и пробирками
- Сектор с камерами наблюдения

## Враги
- Фантомы (только в Эхо-слое)
- Камеры (фиксированные, triggering тревоги)

## Цели контракта
- Образцы (LootItemBase)
- Терминалы с данными ИИ

## Эхо-слой
- Активен в всей локации
- Видны призрачные контуры фантомов сквозь стены
- Глитч-HUD, ложные метки

## Технические требования
- Карта: `M_Sigma`
- Освещение: холодный белый + красный аварийный
- Навигация: NavMesh
- Постпроцесс: Эхо-слой активируется через `UEchoLayerComponent`
