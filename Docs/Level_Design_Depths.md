# Дизайн уровня: M_Depths — Метро «Глубина»

## Обзор
Биом: темнота, вода, фонари, эхо. Враги: стаи, фантомы.

## Ручные якоря
1. **Серверная стойка** — Goal контракта
2. **Комната охраны** — патрули
3. **Лифт** — переход на поверхность
4. **Оружейная** — лут

## Процедурная генерация
- Темные туннели метро
- Платформы с vías
- Затопленные секции (водная поверхность)

## Враги
- Стаи (массовый ИИ, реагируют на свет и звук)
- Фантомы (в Эхо-слое)

## Цели контракта
- Серверная стойка (Terminal)
- Ключ-карта (Keycard)

## Эвакуация
- Точка на поверхности (лифт или лестница)
- При высокой тревоге — Further point

## Технические требования
- Карта: `M_Depths`
- Освещение: тусклые фонари, синий туман
- Навигация: NavMesh + водные зоны (плавание/ходьба по дну)
- Звук: эхо, капли воды, далекие поезда
