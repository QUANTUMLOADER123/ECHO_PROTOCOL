# Дизайн уровня: M_Hub — База «Протокола»

## Обзор
Центральный хаб между контрактами. Игрок выбирает контракт, готовит экипировку, улучшает базу.

## Помещения
1. **Брифинг-комната** — карта со слоями, чек-лист целей, разведданные
2. **Верстак** — крафт и моды оружия (WorkbenchLevel)
3. **Медотсек** — лечение, перки (MedBayLevel)
4. **Архив данных** — разблокировка контрактов и карт (ArchiveLevel)
5. **Оружейная** — закреплённый слот оружия (ArmoryLevel)

## Навигация
- Компас сверху с метками комнат
- Двери между комнатами (ручные якоря)
- Точка сохранения у входа

## Технические требования
- Карта: `M_Hub`
- Освещение: статичное, тёплое освещение базы
- Навигация: NavMesh в всех комнатах
- Звук: эмбиент базы (гудки, Gespräche, клавиатуры)

## Blueprint-объекты
- `BP_BriefingTable` — стол с картой (интерактивный)
- `BP_Workbench` — верстак (интерактивный)
- `BP_WeaponLocker` — оружейная (интерактивный)
- `BP_MedStation` — медотсек (интерактивный)
