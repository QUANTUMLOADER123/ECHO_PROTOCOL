# Дизайн уровня: M_EchoCore — Ядро «ЭХО» (финал)

## Обзор
Биом: абстракция, чёрно-белые переходы, глитчи. Враги: Титан, все типы.

## Ручные якоря
1. **Финальный терминал** — Goal контракта
2. **Босс-арена** — битва с Титаном
3. **Лифт** — центральный хаб ядра
4. **Оружейная** — последний лут перед боссом

## Процедурная генерация
- Абстрактные коридоры с изменяющейся геометрией
- Глитч-платформы (появляются/исчезают)
- Чёрно-белые переходы между секторами

## Враги
- Титан (босс, здоровье 1000)
- Все типы врагов из других биомов

## Цели контракта
- Финальный терминал (DataStick)
- Убийство Титана

## Эхо-слой
- Постоянно активен
- Сильные визуальные искажения
- Фантомы атакуют чаще

## Бой с Титаном
- Убийство Титана отключает турели в секторе
- Открывает проходы
- Снижает тревогу
- Дает доступ к финальному терминалу

## Технические требования
- Карта: `M_EchoCore`
- Освещение: чёрно-белый, фиолетовые акценты Эхо-слоя
- Навигация: NavMesh с динамическими przeszkadami
- Постпроцесс: сильный глитч, хроматическая аберрация, виньетка
