# Дизайн уровня: M_Quartz — Жилой сектор «Кварц»

## Обзор
Биом: разрушенные квартиры, неон, дождь. Враги: патрули, снайперы.

## Ручные якоря
1. **Квартира свидетеля** — NPC для контракта спасения
2. **Комната охраны** — патрули в экзоскелетах
3. **Лифт** — переход между домами
4. **Оружейная** — лут

## Процедурная генерация
- Улицы с неоновыми вывесками
- Коридоры жилых домов
- Квартиры с мебелью и лутом

## Враги
- Патрули (слышат шум, ищут по следам)
- Снайперы (на высотах, лазерный прицел)

## Цели контракта
- Свидетель (NPC)
- Документы (DataStick / Document)

## Эвакуация
- Точка на улице или парковке
- Дождь снижает видимость и шум шагов

## Технические требования
- Карта: `M_Quartz`
- Освещение: неон (розовый, синий), дождь (частицы)
- Навигация: NavMesh + динамические препятствия (развалы)
- Звук: дождь,遠ко sirens, шаги по мокрому асфальту
