# ECHO PROTOCOL — полный дизайн-документ

## 1. Концепция (финальная)
Ты — оперативник «Протокола», элитного подразделения, отправленного в карантинную зону.  
Внутри — корпорация Halcyon Dynamics и её ИИ ЭХО, которые захватили заводы, лаборатории и инфраструктуру города. ЭХО перестраивает реальность: физический мир и «слой данных» накладываются друг на друга.

**Жанр:** стелс-экстракшн PvE от первого лица с элементами иммерсив-сима (как Hitman + Prey + Escape from Tarkov, но PvE и с Эхо-слоем).  
**Ядро:** проникновение на объекты → сбор данных (флешки, терминалы, тела) → выполнение контракта → эвакуация. Смерть = потеря несённого лута, но прогресс базы и «закреплённое» снаряжение сохраняются.

## 2. Геймплейный цикл
ХАБ → выбор контракта → брифинг (разведданные, карта, цели)  
→ инфильтрация (выбор точки входа)  
→ стелс/бой → сбор данных → выполнение целей  
→ эвакуация (точка меняется, зависит от тревоги)  
→ разбор лута → апгрейды базы → новый контракт

**Шкала тревоги (0–100):** растёт от шума, камер, трупов, взломов. На 100 — локация «закрывается», спавнятся элитные отряды, эвакуация усложняется. Тревога спадает медленно, если игрок прячется и глушит сенсоры.

**Эхо-слой:** переключение в реальном времени (заряд + кулдаун). В Эхо-слое:
- видны патрули, слабые точки, скрытые проходы, ловушки;
- оружие слабее, враги-фантомы атакуют;
- HUD искажается (помехи, ложные метки).

**Стелс-механики:** присед, лёжа, скольжение, отвлечение (бросок предмета, взлом камеры, ложный сигнал), маскировка под сотрудника (ограниченное время), бесшумные takedown'ы (только в материальном слое), глушилки сенсоров.

**Экстракшн:** точка эвакуации подсвечивается после выполнения цели. Чем выше тревога — тем дальше и опаснее точка. Лут делится на «карман» (теряется при смерти) и «контейнер» (закреплён, теряется частично).

## 3. Локации (5 биомов, процедурная сборка + ручные «якоря»)
| Биом | Атмосфера | Враги | Ключевые цели |
|------|-----------|-------|---------------|
| Завод «Кобальт» | Ржавчина, пар, конвейеры, искры | Дроны-адапторы, турели | Флешка с производственными логами |
| Лаборатория «Сигма» | Белый кафель, красный аварийный свет, стерильность | Фантомы, камеры | Образцы, терминалы с данными ИИ |
| Метро «Глубина» | Темнота, вода, фонари, эхо | Стаи, фантомы | Серверная стойка, ключ-карта |
| Жилой сектор «Кварц» | Разрушенные квартиры, неон, дождь | Патрули, снайперы | Свидетель (NPC), документы |
| Ядро «ЭХО» | Абстракция, чёрно-белые переходы, глитчи | Титаны, все типы | Финальный терминал, босс |

Ручные «якоря» — фиксированные комнаты (серверная, комната охраны, лифт, оружейная) для читаемости уровня, остальное — процедурная сборка коридоров и залов.

## 4. Враги
- **Дроны-адапторы** — летают, сканируют, запоминают позиции, меняют маршруты. Уязвимы к ЭМИ.
- **Фантомы** — только в Эхо-слое. Атакуют ментально: искажают HUD, крадут заряды, ложные метки. Убиваются «якорем реальности» (гаджет).
- **Турели** — стационарные, взламываются, могут работать на игрока.
- **Патрули (люди в экзоскелетах)** — слышат шум, ищут по следам, вызывают подкрепление.
- **Снайперы** — на высотах, лазерный прицел, требуют обхода.
- **Стаи** — массовый ИИ, окружают, реагируют на свет и звук.
- **Титаны (боссы)** — хабы сектора, убийство меняет локацию (отключает турели, открывает проходы, снижает тревогу).

## 5. Оружие и гаджеты
**Огнестрел (модульный, 4 слота: ствол, прицел, магазин, насадка):**
- Пистолет-пулемёт «Оса» — тихий, слабый, глушитель.
- Штурмовая винтовка «Клинок» — универсал.
- Дробовик «Молот» — ближний бой, громкий.
- Снайперская «Игла» — дальний бой, пробитие.
- Пистолет «Тень» — бесшумный, takedown-ориентированный.
- ЭМИ-винтовка «Разрыв» — против дронов и турелей.

**Гаджеты:**
- Сканер Эхо — подсветка врагов сквозь стены (заряды).
- Глушилка сенсоров — временно отключает камеры/турели.
- Дрон-разведчик — управляемый, малый радиус.
- «Якорь реальности» — принудительный выход из Эхо-слоя, урон фантомам.
- Ложный сигнал — отвлекает патрули.
- Взломщик — терминалы, камеры, турели.
- Аптечка / стимулятор — лечение, ускорение.

## 6. Прогрессия
**База-хаб:** верстак (крафт/моды), медотсек (лечение, перки), архив данных (разблокировка контрактов, карт), оружейная (закреплённый слот).

**Дерево «Протоколов»:** пассивные перки (тише шаг, быстрее взлом, больше зарядов Эхо, крепче контейнер).

**Контракты:** 3 типа — разведка (собрать N флешек), диверсия (уничтожить узел), спасение (вывести NPC). Награда: кредиты, репутация, чертежи.

Экипировка теряется при смерти, кроме «закреплённого» слота и контейнера (частично).

## 7. UI/UX — визуальный стиль
Общая эстетика: «чистый милитари-техно» — тёмный фон, тонкие линии, моноширинные шрифты, минимум декора. Вдохновение: Hitman 3 (чистота), Prey (техно), Cyberpunk (неон акцентов).

**Палитра:**
- Фон интерфейса: #0B0F14 (почти чёрный), панели #131A22.
- Основной текст: #E6EDF3, вторичный #8B98A5.
- Акцент действия: #38E1B0 (мятно-бирюзовый) — кнопки, подтверждения.
- Акцент тревоги: #FF4D5E (красный) — опасность, враги.
- Акцент Эхо-слоя: #7B61FF (фиолетовый) — данные, фантомы, глитчи.
- Предупреждение: #FFB020 (янтарный).

**HUD:**
- Левый нижний — здоровье, броня, стимуляторы (тонкие дуги).
- Правый нижний — оружие, патроны, режим огня.
- Левый верхний — шкала тревоги (сегментная), индикатор Эхо-заряда.
- Правый верхний — цели контракта (чек-лист), таймер.
- Центр — минимальный прицел, метки взаимодействия (тонкая скобка).
- Компас сверху — метки эвакуации, целей, шума.

**Эхо-слой HUD:** фиолетовая сетка, контуры врагов, «шум» из глитч-линий, искажение по краям экрана, ложные метки.

**Меню:** тёмные панели, крупные заголовки моноширинным шрифтом, анимация «сканирования» при переходе. Брифинг — карта со слоями, чек-лист целей, разведданные.

**Шрифты:** заголовки — JetBrains Mono / Space Grotesk; текст — Inter.

## 8. Звук и музыка
- Эмбиент: гул заводов, капли, эхо метро, шум дождя.
- Музыка: минимальный синт-эмбиент, нарастает при тревоге; в Эхо-слое — искажённые тона, реверс-сэмплы.
- Звуковой дизайн: шаги по разным поверхностям, дыхание, шум оружия, сигналы камер, «сердцебиение» при низком HP.
- Стелс-индикация: звук «обнаружения» нарастает по громкости до тревоги.

- PvE-кооператив — массовая аудитория без PvP-баланса.

- Косметика и сезоны — долгосрочный доход.

## 11. Техническая реализация (Unreal Engine 5)
- **Движок:** Unreal Engine 5 (C++ + Blueprints).
- **Архитектура:** модульная — системы (Stealth, Echo, AI, Extraction) как отдельные компоненты/менеджеры.
- **AI:** Behavior Tree + Environment Query System (EQS) для патрулей, адаптивные маршруты через NavMesh + динамические веса.
- **Процедурная генерация:** граф комнат + ручные «якоря», валидация проходимости.
- **Сохранения:** JSON-профиль (база, перки, закреплённый лут), серверная валидация для кооператива.
- **Сетевой код (кооп):** Steam Networking / UE replication, host-authoritative.
- **Арт-пайплайн:** модульные киты (стены, полы, пропсы), PBR-материалы, пост-обработка (Bloom, Vignette, Chromatic Aberration для Эхо-слоя).
- **Порядок сборки:** вертикальный срез (1 локация, 3 врага, 2 оружия, Эхо-слой) → плейтест → расширение.
