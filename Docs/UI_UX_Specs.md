# Спецификации UI/UX (UMG виджеты)

## Стиль: «Чистый милитари-техно»
- Тёмный фон: #0B0F14
- Панели: #131A22
- Текст: #E6EDF3 (Inter / JetBrains Mono)
- Акцент действия: #38E1B0
- Акцент тревоги: #FF4D5E
- Акцент Эхо: #7B61FF

## WBP_HUD (основной экран)
### Левый нижний угол
- Здоровье — тонкая дуга (красная при низком HP)
- Броня — тонкая дуга (синяя)
- Стимуляторы — иконки с таймерами

### Правый нижний угол
- Оружие — название, иконка
- Патроны — в магазине / в резерве
- Режим огня — Авто / Одиночный / Очередь

### Левый верхний угол
- Шкала тревоги — сегментная (0-100), зелёная → красная
- Индикатор Эхо-заряда — фиолетовая полоса

### Правый верхний угол
- Цели контракта — чек-лист
- Таймер миссии

### Центр
- Минималистичный прицел
- Метки взаимодействия — тонкая скобка [E]

### Компас сверху
- Метки эвакуации
- Метки целей
- Метки шума (когда Spieler делает шум)

## WBP_HUD_EchoLayer (перекрытие при активации Эхо-слоя)
- Фиолетовая сетка по экрану
- Контуры врагов (красные/фиолетовые)
- Шум из глитч-линий
- Искажение по краям экрана
- Ложные метки на компасе
- Искажённые иконки оружия

## WBP_Briefing (меню перед миссией)
- Карта со слоями (физический слой / Эхо-слой)
- Чек-лист целей контракта
- Разведданные (текст, фото)
- Рекомендуемое снаряжение
- Кнопка «Начать миссию»

## WBP_HubMenu (меню базы)
- Верстак — крафт/моды оружия
- Медотсек — лечение, перки
- Архив данных — контракты, карты
- Оружейная — закреплённый слот
- Дерево перков — вкладка «Протоколы»

## WBP_PerkTree
- Визуальное дерево с узлами перков
- Стоимость в кредитах
- Предварительные условия (стрелки между перками)
- Статус: заблокирован / доступен / разблокирован

## Шрифты
- Заголовки: JetBrains Mono / Space Grotesk (моноширинные)
- Основной текст: Inter (sans-serif)

## Анимации
- «Сканирование» при переходе в Эхо-слой
- Пульсация шкалы тревоги при росте
- Мигание меток взаимодействия
