# Content/Maps

Карты локаций (5 биомов + хаб):

- `M_Hub` — база «Протокола»
- `M_Cobalt` — Завод «Кобальт»
- `M_Sigma` — Лаборатория «Сигма»
- `M_Depths` — Метро «Глубина»
- `M_Quartz` — Жилой сектор «Кварц»
- `M_EchoCore` — Ядро «ЭХО» (финал)

На каждой карте:
- Ручные якоря (серверная, комната охраны, лифт, оружейная)
- Процедурные коридоры и залы через `BP_DungeonGenerator`
- Точка эвакуации `BP_ExtractionPoint`
- Враги, лут, камеры, турели
