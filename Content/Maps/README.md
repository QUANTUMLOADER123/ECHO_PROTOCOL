# Content/Maps

Карты локаций (5 биомов + хаб):

- `M_Hub` — база операций «Протокола»
- `M_Cobalt` — Завод «Кобальт»
- `M_Sigma` — Лаборатория «Сигма»
- `M_Depths` — Метро «Глубина»
- `M_Quartz` — Жилой сектор «Кварц»
- `M_EchoCore` — Ядро «ЭХО» (финал)

Каждая карта содержит ручные «якоря» (серверная, комната охраны, лифт, оружейная) и процедурно собранные коридоры/залы.
