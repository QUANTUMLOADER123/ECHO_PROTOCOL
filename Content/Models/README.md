# Content/Models — 3D-модели для ECHO PROTOCOL

Все модели импортируются в **Unreal Engine 5** через Content Browser → Import.
Рекомендуемый формат: **.FBX** (модели), **.FBX/.CAD** (мебель, техника).

## Структура папок
```
Content/Models/
├── Weapons/         — Оружие (Оса, Клинок, Молот, Игла, Тень, Разрыв)
├── Gadgets/         — Гаджеты (сканер, глушилка, дрон, якорь, сигнал, взломщик, аптечка)
├── Enemies/         — Враги (патруль, дрон, фантом, турель, снайпер, стая, титан)
├── Props/           — Реквизит (терминалы, флешки, трупы, контейнеры, двери)
├── Environment/     — Окружение (стены, полы, конвейеры, лестницы, анкоры)
└── Player/          — Модель оперативника (первое лицо +руки)
```

## Настройки импорта в UE5
- **Skeletal Mesh** для оружия в руках, врагов, игрока
- **Static Mesh** для всего остального
- **Normal Import Method**: Import Normalals
- **Compression**: No compression для критических моделей, Auto для остальных
- **LODs**: Автогенерация LOD 1-3 для всех моделей > 2000 полигонов

## Оптимизация (меньше места)
- Все текстуры сжимать в **BC7** (PC) или **ASTC** (мобильные)
- Максимальный размер текстуры: 2048×2048 для оружия, 1024×1024 для реквизита
- Использовать **Texture Streaming** для больших уровней
- Удалять неиспользуемые ассеты перед пакетом (File → Audit → Size Map)
