## Структура текстур
```
Content/Textures/
├── Weapons/         — Оружие (Albedo, Normal, Roughness, Metallic)
├── Gadgets/         — Гаджеты
├── Enemies/         — Враги (включая нормальные карты для глитчей)
├── Environment/     — Окружение (кирпич, бетон, кафель, металл)
├── UI/              — Иконки, шрифты, элементы интерфейса
├── EchoLayer/       — Текстуры для Эхо-слоя (сетка, глитчи, контуры)
└── Decals/          — Наклейки (кровь, следы, отверстия от пуль)
```

## Эхо-слой — постпроцесс (PP_EchoLayer)
1. Chromatic Aberration: 0.15 (фиолетовый оттенок)
2. Vignette: 0.6
3. Color Grading: Temperature -0.3, Tint 0.4
4. Bloom: Intensity 1.5, Threshold 0.8
5. Grain: Intensity 0.3 (шумы/глитчи)
